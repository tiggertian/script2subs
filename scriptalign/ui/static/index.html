    DaVinci Resolve checklist
    
    
  
    
  
    
    
    Timecode
    
    
    The insert uses absolute timecode. Set Project Settings → Master
      Settings → Start TC to 00:00:00:00, or add an offset
      equal to your timeline start (e.g. 3600 for
      01:00:00:00).
    
    
    Bilingual burn-in
    
    
    Resolve renders one subtitle track at a time, so use
      bilingual.srt: it has the primary line on top and the second
      language beneath on every cue. Style it once at the track level.
    
    
    Fonts
    
    
    Use a font that covers both scripts — Noto Sans CJK SC or PingFang SC on
      macOS. Western-only fonts fall back per glyph and can look uneven.
    
    
    Delivery
    
    
    YouTube takes the SRT as a caption file. Douyin, WeChat Channels and
      Reels ignore embedded captions — burn the bilingual track into the
      picture for those, and keep a clean master.
